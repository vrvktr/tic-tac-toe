# Tic-Tac-Toe

A responsive, two-player Tic-Tac-Toe game built with React, Vite, and Bootstrap.

## Features

- Alternating turns for X and O
- Winner and draw detection, with winning cells highlighted
- Score tracking across rounds
- Restart the current round or reset all scores
- Responsive layout

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL printed by Vite in your browser.

## Production build

Create an optimized production build:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```
